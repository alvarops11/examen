# ExamSphere - Documentacion Tecnica Completa

Este directorio contiene la documentacion tecnica y funcional del proyecto `ExamSphere`.

Objetivo:
- Que una persona nueva pueda entender el sistema rapidamente.
- Que una IA pueda leer el contexto completo del producto y su arquitectura.
- Que el equipo tenga una referencia estable para mantenimiento y evolutivos.

## Alcance

Esta documentacion describe:
- Estructura real del repositorio.
- Tecnologias y librerias principales.
- Flujo de generacion de examenes y tutor de errores.
- Endpoints, contratos de datos y manejo de errores.
- Instrumentacion de metricas y estadisticas.
- Operacion en local, despliegues y dependencias de infraestructura.

No describe en detalle cada componente de UI de `client/src/components/ui/*`, ya que esa carpeta contiene un set amplio de componentes base reutilizables.
